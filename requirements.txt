# Runtime dependencies for the deployed Streamlit dashboard.
#
# Deliberately minimal: this is the file Streamlit Community Cloud installs, and
# every package here is one that dashboard/app.py actually imports. The analysis
# stack (scikit-learn, matplotlib, Jupyter) lives in requirements-dev.txt so the
# deployment neither waits for it nor fails on it.
#
#     pip install -r requirements-dev.txt      # everything, for the notebooks
#     pip install -r requirements.txt          # just the dashboard
#
# WHY THE ENVIRONMENT MARKERS
# ---------------------------
# Every number in report/main.pdf was produced on Python 3.10 with the exact
# versions pinned below, so those pins hold for Python <= 3.12.
#
# Streamlit Cloud may build on a newer interpreter. numpy 1.26.4 ships wheels
# only up to cp312, so on Python 3.13+ pip finds no wheel, falls back to
# compiling from source, and the build fails - the app then hangs on "Your app
# is in the oven" indefinitely. The markers select a wheel-backed version on
# newer interpreters. Floors on the 3.13+ branch are the first releases that
# publish cp314 wheels.
#
# Deployment target: Python 3.12 (exact pins, identical to local).

streamlit==1.39.0      ; python_version < "3.13"
streamlit>=1.39.0,<2   ; python_version >= "3.13"

pandas==2.2.3          ; python_version < "3.13"
pandas>=2.3.3,<3       ; python_version >= "3.13"

numpy==1.26.4          ; python_version < "3.13"
numpy>=2.3.2,<3        ; python_version >= "3.13"

plotly==5.24.1         ; python_version < "3.13"
plotly>=5.24.1,<7      ; python_version >= "3.13"
